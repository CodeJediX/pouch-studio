# Pouch Studio

Interactive 3D preview of the 16 × 12-inch black laptop pouch.

Drag to rotate, scroll or pinch to zoom, and use Front, Back, Side, Detail, and 3D view controls.

All model textures and viewer dependencies are included. GitHub Pages serves the main branch root. No build step is required.

The pouch is a visual reconstruction of the supplied character sheet; thickness is estimated. Three.js is distributed under the MIT license in vendor/THREE-LICENSE.txt.
